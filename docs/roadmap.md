# Roadmap

1. **v0.1 foundations:** executable, strict configuration, diagnostics, deterministic planning, local checkpoints, metadata resume and tests. No inference.
2. **Read-only agent slice:** validate official CLI versions and existing subscription login, disable unsafe startup configuration, isolate one authorized session, capture structured events and provenance. No implicit API billing.
3. **Bounded editing and verification:** explicit permissions, command approval bound to executable/arguments/cwd/environment, isolated workspace, before/after inventories, durable session recovery, cancellation and reproducible verification records.
4. **Independent review:** exact committed base/head, conservative authorship, eligible reviewer, explicit acceptance, remediation and stale-evidence invalidation across every entry point.
5. **Optional integrations:** audited capability manifests and bounded context gathering; no automatically trusted skills.
6. **Release integration:** separate owner approvals and optional GitHub CI evidence. Branch protection and CI remain independently enforced.

Platform validation expands beyond macOS before portability is claimed as tested. A database, plugin marketplace, autonomous multi-agent runtime and automatic release workflow are not prerequisites for the next slice.
